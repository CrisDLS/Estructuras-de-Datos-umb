# 📗 Parcial 2: Colas de Prioridad Multilenguaje

Práctica correspondiente al **Segundo Parcial** de la materia Estructura de Datos. En este parcial se desarrolla e implementa el TDA **Cola de Prioridad (Priority Queue)** bajo tres representaciones algorítmicas distintas y en tres lenguajes de programación en equipo de 3 personas.

---

## 👥 Equipo y Asignación de Lenguajes

| Lenguaje | Integrante Responsable | Directorio Asignado |
| :--- | :--- | :--- |
| **C++** | Cris | [`Colas_De_Prioridad/cpp/`](Colas_De_Prioridad/cpp/) |
| **Python** | Compañera 1 | [`Colas_De_Prioridad/python/`](Colas_De_Prioridad/python/) |
| **Java** | Compañera 2 | [`Colas_De_Prioridad/java/`](Colas_De_Prioridad/java/) |

---

## 🎯 Modelos de Cola de Prioridad a Desarrollar
1. **Nodos / Lista Enlazada:** Inserción ordenada manteniendo la prioridad más alta en el frente.
2. **Arreglo Desordenado / Ordenado:** Manejo sobre arreglos lineales contiguos.
3. **Montículo Binario (Binary Heap):** Implementación eficiente sobre un arreglo lineal donde la raíz preserva el elemento de máxima/mínima prioridad ($O(\log n)$).

---

## 📂 Organización Interna
Cada lenguaje cuenta con su propio subdirectorio aislado para evitar conflictos de compilación, dependencias y tipos de archivo:
* `cpp/`: Código fuente C++ (Headers `.h` y `main.cpp`).
* `python/`: Código fuente Python (`.py`).
* `java/`: Código fuente Java (`.java`).
