# 🐍 Cola Doble (Bicola / Deque) en Python (`src_python`)
**Origen:** Complemento de integración para el módulo de Colas Dobles

En Python las listas (`list`) son estructuras dinámicas por naturaleza y no existen arreglos primitivos de tamaño fijo de forma nativa, por lo que la estructura **Cola Doble (`ColaDoble`)** se concentra en un único archivo autocontenido con menú interactivo:
* `Colas_Dobles.py`: Clase `ColaDoble` y menú interactivo `interfaz()`.

---

## 🚀 Ejecución

```bash
cd Parcial_2/Colas/Colas_Dobles/src_python
python Colas_Dobles.py
```
