# ↔️ Colas Dobles (Bicola / Deque)
**Segundo Parcial — Estructura de Datos (UMB)**

Implementación del Tipo de Dato Abstracto (TDA) **Cola Doble (`Deque` - Double-Ended Queue)**, que permite insertar y eliminar elementos tanto por el frente como por el final en tiempo constante $O(1)$.

---

| Lenguaje | Directorio | Archivos / Implementaciones | Estado |
| :---: | :---: | :--- | :---: |
| **C++** | [`src_c++/`](src_c++/) | `Arreglos.cpp` (Arreglo circular) y `Nodos.cpp` (Lista doblemente enlazada) | ✅ Completo |
| **Java** | [`src_java/`](src_java/) | *Pendiente de implementar (`DequeArreglo.java`, `DequeNodos.java`)* | ❌ Pendiente |

## 🛠️ Compilación y Ejecución en C++ (`src_c++/`)

```bash
cd Parcial_2/Colas/Colas_Dobles/src_c++

# Compilar y ejecutar versión con Arreglos
g++ -Wall Arreglos.cpp -o arreglos
.\arreglos.exe

# Compilar y ejecutar versión con Nodos
g++ -Wall Nodos.cpp -o nodos
.\nodos.exe
```
