# ⚡ Colas Dobles (Bicola / Deque) en C++ (`src_c++`)
**Origen:** Aportación de otros equipos (Compañeros de grupo)

Implementación en **C++** del TDA **Cola Doble (`Deque`)** bajo dos representaciones en memoria (tipado estático vs. memoria dinámica):
* `Arreglos.cpp`: Implementación mediante **arreglo circular dinámico** en memoria contigua.
* `Nodos.cpp`: Implementación mediante **nodos doblemente enlazados** en el *Heap*.

---

## 🛠️ Compilación y Ejecución

```bash
cd Parcial_2/Colas/Colas_Dobles/src_c++

# 1. Versión con Arreglos
g++ -Wall Arreglos.cpp -o arreglos.exe
.\arreglos.exe

# 2. Versión con Nodos
g++ -Wall Nodos.cpp -o nodos.exe
.\nodos.exe
```
