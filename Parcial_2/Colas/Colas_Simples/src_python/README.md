# 🐍 Cola Simple (FIFO) en Python (`src_python`)

En Python las listas nativas (`list`) son dinámicas por defecto, por lo que el TDA **Cola Simple (`ColaSimple`)** se implementa en un único archivo autocontenido con menú interactivo:
* `Colas_Simples.py`: Clase `ColaSimple` y menú interactivo `interfaz()`.

cd Parcial_2/Colas/Colas_Simples/src_python
