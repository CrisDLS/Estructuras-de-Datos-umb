# ☕ Colas Circulares en Java (`src_java`)
**Origen:** Aportación de otros equipos (Compañeros de grupo)

Implementación en **Java** del TDA **Cola Circular** mediante interfaces y menús interactivos:
* `Colacirculaarreglo.java`: Interfaz `IColaCircularArreglo` y clase `Colacirculaarreglo`.
* `Colacircularnodo.java`: Clase `NodoCircular`, interfaz `ColaCircularNodos` y clase `Colacircularnodo`.

---

## 🛠️ Compilación y Ejecución

```bash
cd Parcial_2/Colas/Colas_Circulares/src_java
javac Colacirculaarreglo.java Colacircularnodo.java

# Ejecutar versión con Arreglo
java Colacirculaarreglo

# Ejecutar versión con Nodos
java Colacircularnodo
```
