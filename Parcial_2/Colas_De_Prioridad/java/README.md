# ☕ Colas de Prioridad en Java

**Responsable:** Karen

Espacio dedicado para la implementación en **Java** de la Cola de Prioridad.

---

## 📋 Estructura Recomendada de Archivos

Puedes organizar tu código de la siguiente manera:
```text
java/
├── ColaPrioridadNodos.java    # Implementación con nodos / lista enlazada
├── ColaPrioridadArreglo.java  # Implementación con arreglo
├── ColaPrioridadHeap.java     # Implementación con montículo binario (heap)
├── Main.java                  # Clase principal con método main()
└── README.md                  # Este archivo de documentación
```

---

## 🛠️ Compilación y Ejecución

### Desde Terminal / Consola
```bash
# Compilar todos los archivos .java
javac *.java

# Ejecutar el programa principal
java Simulador
```

> **Consejo para el equipo:**
> * Los archivos de bytecode `.class` y carpetas de IDEs (`.idea/`, `.settings/`, `bin/`) ya están ignorados por el `.gitignore` raíz.
> * Puedes usar cualquier IDE (VS Code, IntelliJ IDEA, Eclipse o NetBeans).
