# ☕ Colas Simples (FIFO) en Java (`src_java`)
**Segundo Parcial — Estructura de Datos (UMB)**

Dado el tipado estático de Java, se implementan las dos representaciones en memoria:
* `ColaSimpleArreglo.java`: Interfaz `IColaSimpleArreglo` y clase `ColaSimpleArreglo` sobre un arreglo `int[]` fijo.
* `ColaSimpleNodos.java`: Clase `NodoSimple`, interfaz `IColaSimpleNodos` y clase `ColaSimpleNodos` con referencias enlazadas.

---

## 🛠️ Compilación y Ejecución

```bash
cd Parcial_2/Colas/Colas_Simples/src_java
javac ColaSimpleArreglo.java ColaSimpleNodos.java

# Ejecutar versión con Arreglo
java ColaSimpleArreglo

# Ejecutar versión con Nodos
java ColaSimpleNodos
```
