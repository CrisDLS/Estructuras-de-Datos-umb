# ➡️ Colas Simples (FIFO)
**Segundo Parcial — Estructura de Datos (UMB)**

Implementación formal del TDA **Cola Simple (First-In, First-Out)** en los tres lenguajes del Segundo Parcial, diferenciando las estructuras de memoria estática/dinámica según el tipado de cada lenguaje.

---

## 📂 Organización por Lenguaje y Criterio de Tipado

* En **C++ y Java** (tipado fuerte), se implementan tanto la variante mediante **Arreglos** como la variante mediante **Nodos Enlazados**.
* En **Python** (tipado dinámico), donde la lista nativa es redimensionable dinámicamente, se implementa en **un único archivo** (`Colas_Simples.py`).

| Lenguaje | Directorio | Archivos / Implementaciones | Esquema |
| :---: | :---: | :--- | :--- |
| **C++** | [`src_c++/`](src_c++/) | `ColaSimpleArreglo.h`, `ColaSimpleNodos.h` y `main.cpp` | Cabeceras `.h` + único `main` |
| **Java** | [`src_java/`](src_java/) | `ColaSimpleArreglo.java` y `ColaSimpleNodos.java` | Interfaces + Menú interactivo |
| **Python** | [`src_python/`](src_python/) | `Colas_Simples.py` | Archivo único dinámico |
