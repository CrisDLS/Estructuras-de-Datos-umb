# 📘 Parcial 1: Estructuras de Datos Lineales (Python)

Implementaciones de Tipos de Datos Abstractos (TDA) lineales desarrolladas durante el **Primer Parcial** con clases genéricas y pruebas de rendimiento comparativas (reportando tiempos en **milisegundos** y **ticks**, donde $1\text{ tick} = 100\text{ ns}$).

## 🚀 Ejecución de Pruebas

### 1. Demostración General
Desde la carpeta raíz del repositorio o dentro de `Parcial_1/`:
```bash
python Parcial_1/main.py
```

### 2. Pruebas de Rendimiento Individuales
```bash
# Medición en Arreglos
python Parcial_1/Arreglos/Operaciones_Arreglos.py

# Medición en Pilas
python Parcial_1/Pilas/Operaciones_Pilas.py
```
